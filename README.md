# Eyeventory

**Eyeventory** is a smart, intuitive inventory management application built with Flutter and Firebase. It helps you keep track of your groceries, reduce food waste, and manage your kitchen efficiently.

## 🚀 Key Features

### 🍎 Smart Inventory Management

Organize your items into four main dedicated sections:

- **Produce**: Keep track of fresh fruits and vegetables.
- **Essentials**: Manage meats, dairy, and daily necessities.
- **Frozen**: Monitor items in your freezer.
- **Pantry**: Track dry goods, beverages, and shelf-stable items.

### 🔔 Intelligent Alerts

Never let food go to waste again with our smart notification system:

- **Expiring Soon**: Get timely alerts before items go bad.
- **Low Stock**: Know exactly when you need to restock your favorites.
- **Spoiled**: Track waste to improve your buying habits.

### 📊 Store Dashboard & Insights

- **Visual Analytics**: View a breakdown of your inventory by category and status.
- **Quick Filters**: Easily find items that are expiring soon or running low.
- **Detailed Views**: Dive deep into each section to manage specific items.

### ☁️ Cloud Sync & Security

- **Real-time Synchronization**: Powered by Firebase Firestore, your data is always up to date across gadgets.
- **Secure Authentication**: Robust user management ensures your data is private and secure.

## 🛠 Project Structure

The project is structured for scalability and maintainability:

- `lib/screens`: Contains all the UI screens (Auth, Home, Inventory, Store).
- `lib/services`: Firebase and Notification services.
- `lib/widgets`: Reusable UI components.
- `lib/models`: Data models for inventory items.
- `lib/utils`: Constants, helper functions, and themes.

1. **Prerequisites**: Ensure you have Flutter installed and a Firebase project set up.

